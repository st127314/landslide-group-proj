# Data sources, citations and licences

Earth Engine IDs are the ones used in `scripts/gee_landslide_factors.py` (`GEE_ASSETS`), `gee_imerg_antecedent_rainfall.py` and `run_live_gfs_forecast.py`. Please check each provider's current terms before redistributing.

## Landslide events
| Item | Source | Notes |
|---|---|---|
| Landslide inventory (6,180 points, 2000–2025) | Project landslide inventory (provenance recorded in the original spreadsheets) | Original spreadsheets are archived outside this submission folder. |
| Non-landslide points (6,180) | Generated by `scripts/generate_paired_negatives.py` | One synthetic pseudo-absence per landslide (same date and province); see `docs/METHODS.md`. |

## Earth Engine datasets
| Factor / use | Dataset ID | Provider |
|---|---|---|
| Elevation, slope, aspect, curvature, TRI, TPI, LS-factor | `JAXA/ALOS/AW3D30/V4_1` (fallback `USGS/SRTMGL1_003`) | JAXA ALOS World 3D 30 m; USGS/NASA SRTM |
| Flow accumulation, stream distance, TWI, SPI (events before 2020) | `WWF/HydroSHEDS/15ACC` | WWF HydroSHEDS (Lehner et al. 2008) |
| Same, events from 2020 | `MERIT/Hydro/v1_0_1` | Yamazaki et al. 2019, *Water Resources Research* |
| Soil texture, clay, sand, bulk density | `OpenLandMap/SOL/...` (see `GEE_ASSETS`) | OpenLandMap / OpenGeoHub |
| NDVI | `LANDSAT/LT05,LE07,LC08,LC09/C02/T1_L2`, `COPERNICUS/S2_SR_HARMONIZED` | USGS Landsat; ESA Copernicus Sentinel-2 |
| Land cover | `projects/servir-mekong/RLCMSV2/lc_rlcms_logical_v6_remap` (fallback `GOOGLE/DYNAMICWORLD/V1`) | SERVIR-Mekong Regional Land Cover Monitoring System; Dynamic World (Brown et al. 2022, *Scientific Data*) |
| Antecedent rainfall (exploratory rainfall model only) | `NASA/GPM_L3/IMERG_V07` | NASA GPM IMERG |
| Live rainfall forecast (24/48/72 h) | `NOAA/GFS0P25` | NOAA NCEP Global Forecast System |
| Local rainfall percentiles (wet-day 24 h, 1991–2020) | `UCSB-CHG/CHIRPS/DAILY` | Funk et al. 2015, *Scientific Data* (Climate Hazards Group, UC Santa Barbara) |

## External layers (`data/external/`, `data/boundary/`)
| Layer | Source | Licence / citation |
|---|---|---|
| Roads, rivers, waterways, buildings, facilities | OpenStreetMap, Geofabrik Thailand extract, snapshot 2026-09-08 | © OpenStreetMap contributors, ODbL 1.0 |
| Active faults | GEM Global Active Faults Database | CC BY-SA 4.0. Styron & Pagani (2020), *Earthquake Spectra*, doi:10.1177/8755293020944182 |
| Lithology | GLiM v1.1, level-1 classes | Free for scientific/non-commercial use with citation: Hartmann & Moosdorf (2012), *Geochem. Geophys. Geosyst.* 13, Q12004, doi:10.1029/2012GC004370 |
| Population (2020, UN-adjusted, constrained, ~100 m) | WorldPop | CC BY 4.0. Bondarenko, Kerr, Sorichetta & Tatem (2020), doi:10.5258/SOTON/WP00685 |
| Administrative boundaries (provinces, 1,055 tambons) | GADM 4.1 (Thailand) | https://gadm.org — free for academic and non-commercial use |

`data/external/manifest.json`, `validation.json` and `worldpop_manifest.json` record feature counts, extents, retrieval details and (for WorldPop) total/mean/max population.

## Software
Python 3.14, geopandas, scikit-learn, XGBoost, LightGBM, Earth Engine Python API, FastAPI; Next.js + MapLibre for the demo app. Pinned/minimum versions are in `requirements.txt`.
